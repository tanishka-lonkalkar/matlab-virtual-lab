# 🧪 Virtual Lab - Double Integration

A simple interactive **Virtual Lab web project** designed to help students understand the concept of **Double Integration** through theory, simulation, and MCQ practice.

---

## 📌 Project Overview

This project demonstrates:
- Concept of **Double Integration**
- Interactive simulation to evaluate integrals
- MCQ-based self-assessment test
- Structured learning with theory section
- Group project contribution display

---

## 🚀 Features

### 📖 Aim Section
Explains the objective of the experiment.

### 📚 Theory Section
Covers:
- Definition of double integration
- General form: ∬ f(x, y) dA
- Applications in area, volume, and physics

### 🧮 Simulation
- Input-based calculator for evaluating:
  ∬(ax + by + c)
- User enters coefficients and limits
- Instant result display

### 📝 MCQ Test
- 10 multiple-choice questions
- Instant scoring system (/10)
- Helps in self-evaluation
